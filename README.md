# दिव्य जाप (Divya Jaap Mala App) 🕉️

एक पूर्ण, सात्विक एवं एकल-उद्देश्यीय हिन्दू मंत्र जाप व माला काउंटर ऐप।

---

## 🌟 प्रमुख विशेषताएं (Key Features)

1. **अनिवार्य ऑनलाइन चेक (Online Compulsory for Ads):**
   - यदि इंटरनेट बंद होगा, तो ऐप सात्विक चेतावनी स्क्रीन दिखाकर डेटा/Wi-Fi ऑन करने का अनुरोध करेगा, जिससे विज्ञापनों का लोड होना सुनिश्चित होता है।
2. **साधक संकल्प प्रोफाइल (Personalization):**
   - साधक का **नाम**, **गोत्र**, **कुल देवता/देवी**, और **इष्ट देवता** का चयन।
   - इष्ट देवता के अनुसार होम स्क्रीन पर स्वतः अनुकूलित मंत्र और शुभ मुहूर्त सुझाव।
3. **5-6 श्रेणियों में शास्त्रीय मंत्र लाइब्रेरी:**
   - प्रत्येक प्रमुख देवता (शिव, हनुमान, कृष्ण, राम, दुर्गा/काली, गणेश, भैरव) के लिए:
     - 🔱 **नाथ / शाबर मंत्र** (गुरु गोरखनाथ परंपरा)
     - 📜 **ग्रंथ व वैदिक मंत्र** (वेद, उपनिषद, पुराण)
     - 🔴 **तांत्रिक व बीज मंत्र** (ऊर्जा जाग्रत करने वाले)
     - 💀 **अघोरी व महाकाल साधना मंत्र** (भय व संकट नाशक)
     - 📿 **साधु, सिद्ध व नाम मंत्र** (सहज भक्ति व मुक्ति)
4. **कस्टम मंत्र लेखन (Any Language):**
   - यूजर किसी भी भाषा (हिंदी, संस्कृत, अंग्रेज़ी आदि) में अपना गुरु मंत्र या चालीसा लिखकर जाप कर सकता है।
5. **माला आधारित लक्ष्य (Mala Target Setting):**
   - 1 माला (108), 3 माला, 10 माला, 21 माला, 51 माला, 108 माला, 1000 माला, या कोई भी कस्टम माला संख्या।
6. **स्मार्ट स्पीकर मोड (Text-to-Speech Engine):**
   - लिखे गए मंत्र को स्पष्ट आवाज में उच्चारण करता है और हर उच्चारण के बाद स्वतः 1 काउंट आगे बढ़ाता है।
   - गति नियंत्रण: 0.75x, 1.0x, 1.25x.
7. **दिव्य ध्वनि व कंपन (Sound & Haptics):**
   - हर 1 काउंट पर: **मंदिर की पीतल घंटी ("टन्न...")**
   - 108 काउंट (1 माला पूर्ण) पर: **पवित्र शंखनाद ध्वनि ("भोओओओ...")** + डबल हैप्टिक वाइब्रेशन व बधाई।
8. **स्मार्ट प्री-लोडेड ऐड्स व धार्मिक स्टोर:**
   - बिना ध्यान भटकाए नीचे स्थित Native Advance Ad कार्ड।
   - प्रामाणिक रुद्राक्ष, तुलसी माला, धूपबत्ती के एफिलिएट प्रोडक्ट कार्ड्स।

## 🚀 चलाने का तरीका (Run & Build)

### डेवलपमेंट सर्वर चालू करें:
```bash
npm run dev
```
ब्राउज़र में `http://localhost:3000` खोलें।

### प्रोडक्शन बिल्ड:
```bash
npm run build
```

---

## 📱 Android APK में बदलना (Convert to Android App)
इस ऐप को Capacitor या TWA के माध्यम से केवल 1 कमांड में Google Play Store हेतु Android APK में बदला जा सकता है:
```bash
npx cap init "Divya Jaap" "com.divyajaap.app"
npx cap add android
npx cap copy
npx cap open android
```
